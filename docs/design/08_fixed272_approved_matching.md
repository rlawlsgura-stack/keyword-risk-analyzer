# FIXED272 Kiwi 내용어 기반 일부 일치

2026-10-23 · 로컬 구현 · 미배포

## 실행과 버전

```powershell
.\.venv\Scripts\python.exe -m streamlit run keyword_app2_fixed272.py --server.port 8502
```

FIXED271 실행 파일은 그대로 보존합니다. 기존 공통 엔진과 FastAPI를 변경하지 않고
FIXED272만 `approved_matching.py`를 사용합니다. Render 및 Community Cloud의 실행 파일은
이번에 변경하지 않았습니다. 기존 서버는 자동으로 FIXED272로 전환되지 않습니다.

## 사용법

1. 관리자 로그인 → 키워드 관리 → 공통 분석 규칙 → 일부 일치 — 승인된 부분 표현.
2. 키워드를 선택하고 허용할 부분 표현을 한 줄에 하나씩 입력한 뒤 승인 표현 저장.
3. 분석하기 → 키워드 일부 일치 → 텍스트 분석하기.

등록 키워드와 입력 문장을 모두 Kiwi로 분석하여 같은 내용어 토큰이 있으면 승인 없이 검출합니다.
예: 노화방지의 노화 토큰과 입력 노화 피부의 노화 토큰이 같으면 노화방지를 검출합니다.
자동으로 나뉘지 않는 전문 용어는 승인 표현으로 보완합니다.
예: 등록 안티에이징에 에이징을 승인하면 에이징 관리도 검출합니다.
빈 목록을 저장하면 수동 승인만 제거하며 자동 내용어 검사는 계속 적용됩니다.
의미 없는 조각을 승인하면 검출될 수 있으므로 관리자가 업무 의미를 판단해야 합니다.
등록된 이름 자체가 바뀌면 기존 승인은 적용되지 않으며 다시 승인해야 합니다.

## 검출 계약

- 등록 키워드(기존 괄호 옵션 적용)와 입력 양쪽에서 내용어 토큰을 추출합니다.
- 토큰의 형태 전체가 같으면 원문의 해당 토큰 위치를 반환합니다. 토큰 내부 글자 조각은 비교하지 않습니다.
- 등록 표현 전체와 승인된 부분 표현의 경계 검사를 함께 수행하여 자동 분석을 보완합니다.
- 문자열 비교는 기존 공백·기호·대소문자 옵션과 원문 위치 매핑을 재사용합니다.
- Kiwi로 원문을 분석하고 후보 시작·끝이 내용어 토큰 경계에 일치할 때만 통과합니다.
- 글자를 정규화해 붙이더라도 원문 단어의 중간에서 잘라 만든 조각은 통과하지 않습니다.
- 같은 키워드의 중복·포함 구간은 정리하고 다른 키워드 번호는 보존합니다.
- 내용어 한 개만 같아도 후보입니다. 관리·방지 등 일반적인 단어도 검출 근거가 될 수 있습니다.
- 괄호 설명 제외를 끄면 괄호 안의 내용어도 검사하며, 공백 옵션과 관계없이 서로 다른 토큰을 한 토큰으로 합치지 않습니다.
- 반복 등장 위치를 모두 반환합니다. 기존 하이라이트·클릭 팝업·표·CSV·집계 계약을 유지합니다.
- 완전 일치는 기존처럼 단어 내부 표현도 검출할 수 있습니다. 탐색용에는 승인·경계 검사를 적용하지 않습니다.
- API의 similar는 기존 호환 로직입니다. FIXED272 화면의 일부 일치와 동일하지 않습니다.

## 저장과 권한

관리자만 저장할 수 있습니다. Supabase 모드는 기존 kra_settings의
approved_partial_expressions_v272에 키워드 번호별 `{term, expressions}`를 저장합니다.
로컬 CSV 모드는 프로젝트의 approved_partial_expressions_v272.json에 저장합니다.
기본 목록은 비어 있고, 이번 구현에서 운영 DB를 변경하거나 실제 표현을 승인하지 않았습니다.
설정은 다음 분석 때 다시 읽습니다. 로컬 JSON은 임시 파일을 교체하는 방식으로 저장합니다.
클라우드 설정은 기존 전체 설정 저장 방식을 사용하므로 동시 관리자 저장에는 마지막 저장이
반영될 수 있습니다. 승인 작업은 한 관리자가 수행하는 운영을 권장합니다.

## 제한과 오류

이 기능은 의미 판단 모델이나 동의어 검색이 아닙니다. 내용어 토큰 일치와 승인 목록·경계 검사입니다.
Kiwi는 미등록어를 명사로 추정할 수 있어 품사만으로 의미 유무를 판정할 수 없습니다.
전문 용어·합성어의 분해에 따라 누락 또는 의도와 다른 경계가 생길 수 있습니다.
사용자 사전 자동 등록은 이번 범위에 포함하지 않습니다.
Kiwi가 같은 기본형으로 분석한 동사·형용사는 활용형이 달라도 공통 내용어로 검출될 수 있습니다.
독립적인 동의어 확장이나 전체 문장의 의미·부정 판단은 수행하지 않습니다.
구두점으로 시작하거나 끝나는 표현은 경계 검사 때문에 누락될 수 있으므로 별도 검수합니다.
승인 표현 저장은 업무상 유효성을 관리자가 판단한다는 뜻이며 검색 성공을 보장하지 않습니다.
Kiwi 설치·실행 실패나 설정 조회 오류 시 조각 검색으로 자동 대체하지 않습니다.

## 검증

`tests/test_approved_matching.py`에서 실제 Kiwi로 승인 전후, 반복 위치, 이모지 원문 위치,
노화 문장의 승인 없는 다중 키워드 검출,
마사지 방법/피부과/티에이 오검출, 필터, 중복 키워드, 등록명 변경, 기존 두 모드 보존,
키위 오류, 정규화 옵션을 확인합니다. Streamlit AppTest와 가짜 저장소로 관리자 승인,
일반 사용자 버튼 비노출, 하이라이트·CSV 표 형식·집계 연결을 확인합니다.
실제 운영 DB 저장·클라우드 배포·사용자 광고 표본의 정확도는 아직 검증하지 않았습니다.
