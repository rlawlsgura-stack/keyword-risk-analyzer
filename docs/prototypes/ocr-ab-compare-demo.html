찾은 차이

변경A안: 피부가 촉촉해집니다.B안: 피부장벽을 개선하고 주름을 완화합니다.

수정 안내 초안

  1. B안에 새로 추가된 “피부장벽 개선”, “주름 완화” 표현을 확인해 주세요.
  2. 해당 표현을 뒷받침하는 근거 자료와 허용 범위를 확인한 뒤 문구를 확정하세요.
  3. 검토 완료 후 수정본을 다시 비교해 남은 차이를 확인할 수 있습니다.
검토 참고: 화면의 강조 표시는 OCR 문구 차이를 보여주는 예시입니다. 차이가 있다는 사실만으로 위반 여부나 수정의무를 자동 판정하지 않으며, 최종 안내는 담당자가 근거를 확인해 확정해야 합니다.

가능성 검토

구현 가능성 높음
현재 OCR 응답에 텍스트와 좌표 정보가 있어, 변경된 문구를 이미지 위의 위치로 표시할 수 있습니다.

해시의 역할
SHA-256은 파일이 완전히 같은지 빠르게 확인하는 데 적합합니다. 이미지 안의 변경 위치를 찾아주지는 않으므로 OCR 차이와 함께 써야 합니다.

초기 범위 권장
기존 OCR 형식인 PNG/JPG/JPEG/WEBP/BMP부터 시작하고, PDF는 페이지별 이미지 변환·좌표 정합 처리가 추가로 필요합니다.

정확도 한계: 크기 조정·회전·잘림·압축·배경 변화가 크면 좌표가 어긋나거나 OCR 결과가 달라질 수 있습니다. “A안을 기준으로 B안의 변경을 확인”하는 검토 보조 기능으로 설계하는 것이 안전합니다. 실제 법적 수정 지시는 별도 기준과 사람의 검토가 필요합니다.
정적 UI 시안 · 실제 업로드, OCR 비교, 원본 저장, PDF 보고서 생성은 실행되지 않습니다.
