개선 제안 시안
A · 검수 별칭건강기능식품
광고 문구몸무게 줄이기
관리자가 검수한 별칭 → 등록어 ‘체중 감량’의 기준 확인원문 위치 연결
B · 탐색 후보화장품
광고 문구피부과 방문 안내
‘피부 보습’과 ‘피부’ 2글자 일치 → 문맥 확인 필요탐색 경로 표시
검토 우선순위는 매칭 근거의 강도입니다. 위험 등급이나 법적 판단을 자동 변경하지 않습니다.
