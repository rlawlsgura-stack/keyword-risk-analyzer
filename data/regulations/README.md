# 규정 원문 수집본

2026-10-22 국가법령정보센터에서 수집한 초기 참고 자료입니다.
`source_snapshots`에는 화장품법 제13조, 식품표시광고법 제8조, 표시광고법 제3조의
공식 조문 페이지 HTML과 텍스트 추출본을 보관했습니다.

원문 URL, 수집일, 페이지에 표시된 법률 버전과 파일 해시는 `source_manifest.json`에 기록했습니다.
해시는 Git의 개행 변환에 영향을 받지 않도록 UTF-8 텍스트의 개행을 LF로 정규화해 계산합니다.
페이지 머리의 시행일은 관찰 정보이며 모든 조항의 개별 적용일을 검수했다는 뜻은 아닙니다.

현재 상태는 **수집 완료·법률 검수 전**입니다. Supabase 적재, 임베딩 생성, 검색 기능 연결은
수행하지 않았습니다. 원문의 예외·위임 조항과 관련 시행령·시행규칙·고시를 함께 검수한 뒤 사용해야 합니다.
운영 시점에는 개정 여부를 다시 확인해야 하며 이 파일을 최신 법령 전체로 취급하지 않습니다.

외부 AI API 연동은 사용자 요청에 따라 보류했습니다. 연결 시험에서는 API 잔액 부족 응답을 받아
임베딩이 생성되지 않았습니다. API 키와 계정 정보는 수집본에 포함하지 않습니다.
